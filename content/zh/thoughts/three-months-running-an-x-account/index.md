我认真运营 X，大概有三个月了。

这三个月里，我一直在观察一个问题：

**为什么有些账号粉丝不算多，但一条帖子可以获得非常高的曝光；有些账号粉丝很多，发出来的内容却很难获得推荐？**

一开始，我也和很多人一样，把注意力放在点赞、转发、粉丝数量这些表面数据上。

但最近我重新研究了一遍 X 公开的推荐算法，又观察了两个完全不同的账号，我发现事情可能没有那么简单。

所以这篇文章不是一篇“X 运营教程”。

这是我把**三个月的实际观察 + X 公开的推荐算法 + 两个真实账号的对比**放在一起之后，目前得到的一套理解。

先说结论。

## 一、第一件事：先让 X 知道你是谁

这是我现在认为最重要的一点。

X 在 2023 年第一次公开了推荐算法的部分源代码。到了 2026 年，又公开了更新后的 **X For You Feed Algorithm**，也就是现在直接负责 For You 信息流推荐的一套核心代码。

我真正看进去以后，发现一个很重要的事情：

**X 并不是简单地判断“这条帖子有多少点赞”，然后决定给多少曝光。**

它首先需要理解的是：

> **这个用户是谁？这个用户平时关注什么？他会和什么内容互动？这条帖子可能适合什么样的人？**

现在公开的推荐代码里，Phoenix 会读取用户近期的行为历史，并预测这个用户看到某条帖子之后可能发生什么行为。

这些行为包括：

- 点赞
  
- 回复
  
- 转发
  
- Quote
  
- 点击帖子
  
- 点击个人主页
  
- 展开图片
  
- 观看视频
  
- 停留时间
  
- 关注作者
  
- “不感兴趣”、屏蔽、举报等负向行为
  

然后系统综合这些预测结果，对帖子进行排序。

这让我重新理解了一个问题：

**一个账号到底是什么，并不是你自己说了算，X 会通过你的持续行为去判断。**

你发什么内容。

你和谁互动。

你回复什么帖子。

你关注什么人。

别人又会不会和你互动。

这些东西长期积累以后，都会帮助系统理解你的兴趣和你的内容属于什么范围。

所以，如果你想做一个长期账号，我现在反而不会特别纠结“我要不要在每条帖子里加 [#buildinpublic](https://x.com/search?q=%23buildinpublic&src=hashtag_click)”。

我更在意的是：

**我的最近几十条主帖，是不是一直在告诉 X，我是一个什么样的人？**

比如我现在做的是：

> 独立开发 + 开源 + AI 工具 + 公开构建

那么我的内容就应该长期围绕这个范围。

不是说一条都不能跑题。

而是如果 70% 以上的内容都在这个方向里，剩下 30% 再拿来发一些个人思考、生活、吐槽，其实就已经比较清晰了。

我现在越来越觉得：

**账号定位不是写在 Bio 里的那句话，而是你持续发出来的内容和持续产生的互动。**

## 二、第二件事：互动质量，比单纯点赞重要得多

这一点，是我研究算法以后变化最大的地方。

过去我会很自然地认为：

> 点赞越多 → 帖子越受欢迎 → X 就会继续推荐。

但公开的推荐机制并不是这么简单。

X 现在公开的 Phoenix 推荐模型，会预测用户对一条帖子产生各种行为的概率，而不是只看一个“点赞数”。

所以对于一个做账号的人来说，我现在更关注的是：

**用户看到我的帖子以后，到底有没有真正发生行为。**

比如：

点赞当然有价值。

但回复、Quote、点击、展开图片、观看视频、停留，以及之后继续访问你的主页、关注你，都可能成为更有意义的用户信号。

所以我现在运营账号，会把自己的时间更多放在：

**自己的评论区 > 同赛道陌生人的评论区 > 无意义点赞**

尤其是自己的帖子下面有人认真回复时，我会尽量认真回复。

因为这不只是“礼貌”。

它意味着一条帖子从：

> 我发了一条内容

变成了：

> 我发了一条内容 → 有人产生兴趣 → 留下回复 → 我继续回应 → 形成了一段真实对话

这和单纯几十个人点个赞，是完全不同的互动结构。

所以我现在给自己的原则很简单：

**回对的人，比回更多的人重要。**

## 三、对比两个账号

研究算法是一回事。

真正让我确认这些想法的，是我开始观察两个完全不同的账号。

一个是 [@xupaopaogm](https://x.com/@xupaopaogm)。

另一个是 [@cgnot996](https://x.com/@cgnot996)。

他们的内容风格、受众结构和账号定位差异非常明显。

### 徐跑跑

徐跑跑有一个非常明显的特点：

**他的内容很容易让人停下来。**

很多内容并不需要用户先了解复杂的技术背景，而是能够直接制造好奇、争议或者讨论。

于是用户会：

> 看到 → 停留 → 评论 → 争论 → Quote → 继续看评论 → 作者继续回复

从推荐算法的角度看，这其实非常有意思。

因为 X 公开的模型本身就在预测这些行为。

所以我现在不会简单地把它理解成：

> “他的帖子点赞很多，所以 X 推他。”

更准确的理解应该是：

> **他的内容非常容易触发一系列连续的用户行为。**

这才是我觉得真正值得研究的地方。

顺带一提，徐跑跑在最近一次创作者收益审核中遇到了暂时没有通过的情况。

但我认为这件事情本身不能证明什么长期规律。

下一次审核结果完全可能不同。

所以我更关心的，其实不是“这个账号能不能变现”，而是：

**为什么他的内容能够持续制造这么多用户行为？**

### 铁柱 AGI

铁柱 AGI 则完全是另一种模式。

他的账号规模并不算特别大，大约几千粉丝，但内容非常垂直：

**Grok、AI、Codex、开发工具、开源项目、产品实践。**

他的很多主帖不是为了制造争议，而是直接展示：

- 产品
  
- 功能
  
- 截图
  
- 使用体验
  
- 技术信息
  
- 价格对比
  
- AI 工具实践
  

但其中一些原创产品型帖子，依然能够获得非常高的曝光。

这让我注意到了一个非常重要的区别：

**粉丝数量并不能直接代表一个账号内容能够获得多少推荐。**

一个几千粉丝的账号，如果它的内容和一群明确的人高度相关，那么它依然可能不断从自己的关注者之外获得推荐。

而 X 公开的算法也确实存在这样的机制：

For You 不只是从你关注的人那里找帖子，还会通过 Phoenix、SimClusters 等机制，从你没有关注的账号中寻找可能相关的内容。

这两个账号放在一起看，我反而更容易理解 X 的推荐逻辑了。

一个账号可以通过**强烈的用户行为**获得推荐。

另一个账号可以通过**非常明确的内容和受众匹配**获得推荐。

它们的形式完全不同。

但底层都指向了一件事情：

**你到底在向 X 提供什么样的内容，以及 X 能不能找到可能对这些内容感兴趣的人。**

## 四、所以我现在对账号定位的理解变了

以前我理解的账号定位是：

> Bio 写清楚自己是谁。

现在我觉得远远不够。

真正的定位应该是：

> **让 X 能够通过你的内容和互动，持续判断你是谁。**

所以如果让我现在重新开始做一个 X 账号，我不会一上来就追求很多粉丝。

我会先做一件事情：

**让自己的账号变得足够清晰。**

比如：

- 主方向：独立开发
  
- 第二方向：开源 / AI 工具 / 公开构建
  

然后持续输出。

这样做的好处是，当一条内容表现不错的时候，我希望 X 找到的是：

**可能真的对独立开发、AI、开源感兴趣的人。**

而不是随机找一群人把数字堆起来。

## 五、互关可以做，但我不会再把它当成增长模式

我现在对互关的态度也发生了变化。

刚开始冷启动的时候，找 20～50 个和自己内容方向一致、并且真的活跃的人，我认为没有问题。

因为你需要建立最初的关系网络。

而且这些人如果真的对你的内容感兴趣，后续产生回复、Quote、转发，本身就是正常的用户行为。

但如果变成：

> 今天关注 500 个人  
> 明天等 500 个人回关  
> 然后互相点赞

我觉得意义就很有限了。

因为你真正需要建立的不是一个“互关名单”。

而是一个：

**与你内容方向高度相关的关系网络。**

所以我现在的理解是：

> **互关是冷启动工具，不是增长模式。**

## 六、社群可以加，但不要把社群变成刷量工具

这一点我也会做，但会非常谨慎。

如果一个社群里面的人本身就在使用 X，而且大家确实对 AI、独立开发、开源、产品这些内容感兴趣，那么它可以帮助一个新账号获得第一批真实的互动。

但如果规则变成：

> 每个人发帖以后，所有人必须点赞、评论、转发。

那就完全是另外一回事了。

我更愿意把社群理解成：

**加速第一波真实互动的地方。**

而不是：

**制造虚假数据的地方。**

内容本身还是最重要的。

# 最后，这是我接下来会怎么做

研究完算法，又观察了这两个账号之后，我现在给自己定了一套非常简单的执行方式。

**第一，定位保持清晰。**

独立开发 + 开源 + AI + 公开构建。

**第二，主帖少一点，但认真一点。**

我宁愿每天 1～3 条真正有东西的内容，也不想一天发十几条没有价值的水帖。

**第三，评论的权重很高。**

研究 X 的推荐机制后，我发现评论不是简单的“互动数据”，而是重要的用户行为信号。

所以相比单纯追求点赞，我会更重视真实的评论和对话：

> **自己的评论区 > 同赛道陌生人的评论区 > 无意义点赞**

**回对的人，比回更多的人重要。**

**第四，主帖不要放外部链接。**

在 X 的算法里，**主帖放外部链接会影响推荐，所以如果目标是涨粉，我会把链接放到评论区。**

主帖先让用户停留在 X 里完成阅读和互动，链接需要放的时候，再放评论区。

**第五，不追求每条帖子都爆。**

我真正想做的是让 X 越来越清楚：

> 张三疯的风是谁？

> 他主要做什么？

> 什么样的人会喜欢他的内容？

如果这个问题越来越清晰，我认为账号的长期增长才会开始变得可预测。

这也是我研究 X 推荐算法三个月以后，目前最重要的一个结论：

**运营 X，不只是想办法让一条帖子获得更多曝光。**

**而是持续告诉 X：你是谁，你在做什么，以及什么样的人应该看到你的内容。**
